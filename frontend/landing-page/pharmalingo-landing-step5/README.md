# PharmaLingo landing page

A responsive, static marketing landing page for PharmaLingo. No build step or dependencies are required.

## Preview
Open `index.html` in your browser, or run `python3 -m http.server 8000` from this directory and visit http://localhost:8000.

## Publish for free
Create a GitHub repository and upload these files. On a static hosting provider such as GitHub Pages, publish the root directory. You can also import the repository into Vercel as a static site (no build command; output directory `.`). Check hosting plan terms if using it commercially.

## Before publishing
- Replace **hello@example.com** in `index.html` with your real contact email or a working form URL.
- Replace the example translation UI with actual product screenshots when available.
- The translation widget is a **static visual demo**, not a working translator.
- Only publish claims you can verify. The site currently describes internal pilot testing, not a production launch.
- Do not expose real patient data in demos or screenshots.
- Optionally add your app link and a custom domain later.
